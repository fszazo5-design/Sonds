# سندس دي أنا — خطتي الصحية

تطبيق خطة تغذية عربي لسندس بواجهة React داخل غلاف Android أصلي مكتوب بـ Kotlin. يعرض التطبيق أحدث واجهة من GitHub Pages، ويحتفظ بنسخة React محلية احتياطية إذا انقطع الاتصال. تُحفظ بيانات الوجبات في SQLite على الجهاز.

## المزايا

- أوقات الوجبات قابلة للتعديل وتبقى محفوظة بين مرات التشغيل.
- ساعة تناظرية ورقمية حيّة، تتحرك عقاربها مع الوقت وتعرض الوجبة القادمة.
- تخزين الحالة والجدول محليًا في SQLite داخل مساحة التطبيق الخاصة؛ لا يتطلب حسابًا أو خادم بيانات.
- إشعارات مواعيد الوجبات المحلية، مع إعادة الجدولة بعد إعادة تشغيل الهاتف أو تغيير الساعة.
- تشغيل ملف «From The Start» المرفق مع تنبيه كل وجبة عبر قناة إشعارات Android مخصصة.
- **تحديث واجهة React هوائيًا:** تُنشر تغييرات الواجهة إلى GitHub Pages عند الدفع إلى `main`، ويجلبها التطبيق دون تنزيل APK أو تثبيته.
- تغييرات Kotlin أو صلاحيات Android تتطلب إصدار APK أصليًا جديدًا؛ لا يلزم إصدار APK لتغييرات React المعتادة.
- أذونات الإشعارات والكاميرا والميكروفون مع طلبها من المستخدم عند اختياره. لا تستخدم الواجهة الحالية الكاميرا أو الميكروفون.

## التحديث الهوائي

- موقع الواجهة: <https://fszazo5-design.github.io/Sonds/>.
- تُنشر الواجهة تلقائيًا عبر `.github/workflows/pages.yml` بعد كل دفع إلى `main`.
- يعرض التطبيق الواجهة المنشورة عند التشغيل، ويمكن استخدام زر التحديث أعلى الشاشة لجلبها فورًا. عند انقطاع الشبكة يعود تلقائيًا إلى ملفات الواجهة المضمّنة في APK.
- لا يُشغّل `.github/workflows/android-apk.yml` على كل دفع للواجهة؛ يعمل لإصدارات Android الموسومة `v*` أو عند تشغيله يدويًا، ويُستخدم فقط عند تغيير Kotlin أو ملفات Android الأصلية.

## البناء المحلي

المتطلبات: Node.js وJDK 17+ وAndroid SDK API 35.

```bash
npm ci
npm run build
cd android
./gradlew assembleDebug
```

الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk` (نسخة debug قابلة للتثبيت للتجربة). إعداد التوقيع والإصدارات الأصلية موضّح في [android/README.md](android/README.md).
