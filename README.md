# سندس دي أنا — خطتي الصحية

تطبيق خطة تغذية عربي لسندس بواجهة React داخل غلاف Android أصلي مكتوب بـ Kotlin. تُحمّل الواجهة المحدثة كحزمة OTA من GitHub Releases وتُخزّن داخل التطبيق؛ عند انقطاع الشبكة يعمل التطبيق بآخر حزمة مثبتة أو بالواجهة المضمّنة في APK. تُحفظ بيانات الوجبات في SQLite على الجهاز.

## المزايا

- أوقات الوجبات قابلة للتعديل وتبقى محفوظة بين مرات التشغيل.
- ساعة تناظرية ورقمية حيّة، تتحرك عقاربها مع الوقت وتعرض الوجبة القادمة.
- تخزين الحالة والجدول محليًا في SQLite داخل مساحة التطبيق الخاصة؛ لا يتطلب حسابًا أو خادم بيانات.
- إشعارات مواعيد الوجبات المحلية، مع إعادة الجدولة بعد إعادة تشغيل الهاتف أو تغيير الساعة.
- تشغيل ملف «From The Start» المرفق مع تنبيه كل وجبة عبر قناة إشعارات Android مخصصة.
- **تحديث واجهة React هوائيًا من GitHub Releases:** ينشر GitHub Actions حزمة ZIP ببصمة SHA-256 عند الدفع إلى `main`؛ ينزّلها التطبيق ويتحقق منها ويثبتها محليًا دون الاعتماد على GitHub Pages.
- تعديلات React وCSS لا تتطلب APK جديدًا بعد تثبيت إصدار Android الداعم لمسار GitHub Releases. أما تغييرات Kotlin أو AndroidManifest أو الأذونات أو سلوك المنبهات فتتطلب APK جديدًا.
- أذونات الإشعارات والكاميرا والميكروفون يظهر طلب السماح بها عند فتح التطبيق، ويمكن إعادة طلبها من إعدادات الجهاز داخل التطبيق.
- صفحة «أوقاتي» تتيح تعديل أوقات الوجبات ومكوناتها وترتيبها، مع حفظ البيانات محليًا.
- زر «أغنيتي المفضلة مع سندس» في الصفحة الرئيسية يفتح فيديو الكلمات المدمج داخل التطبيق، ويعمل في النسخة المحلية دون الحاجة إلى اتصال.

## التحديث الهوائي لواجهة React

- مستودع المصدر: <https://github.com/fszazo5-design/Sonds>.
- ينشر `.github/workflows/ui-ota.yml` حزمتي `Sonds-UI.zip` و`Sonds-UI.json` إلى إصدار GitHub Release المخصص `ui-ota` بعد كل دفع إلى `main`.
- عند تشغيل التطبيق، يفحص إصدار الواجهة ويحمّل الحزمة الأحدث من GitHub Releases؛ ويمكن بدء الفحص فورًا بزر التحديث أعلى الواجهة.
- يتحقق التطبيق من بصمة SHA-256 للحزمة قبل فكّها وتثبيتها، ويستبدل النسخة السابقة بعد اكتمال التثبيت. تُحمّل ملفات الواجهة من مساحة التطبيق المحلية، لا من GitHub Pages.
- في حال تعذّر الاتصال أو فشل التحقق، يحتفظ التطبيق بآخر واجهة مثبتة، ثم يرجع إلى الواجهة المضمّنة في APK إذا تعذّر فتح النسخة المثبتة.
- هذا المسار يتطلب تثبيت APK Android جديد مرة واحدة لتحديث التطبيق الأصلي من التحميل المباشر لصفحة الويب إلى تنزيل حزمة OTA من GitHub Releases؛ بعد ذلك، تحديثات React وحدها لا تحتاج APK.

## تحديث APK الأصلي

- من «إعدادات الأذونات» اختر «تحديث نظام Android (APK)» عند نشر إصدار Android جديد؛ ينزّل التطبيق `Sonds.apk` من أحدث GitHub Release ويطلب Android تأكيد التثبيت.
- يبني `.github/workflows/android-apk.yml` APK عند دفع tag يبدأ بـ `v`، أو عند تشغيل workflow يدويًا.
- يلزم السماح مرة واحدة لتطبيق سندس دي أنا بالتثبيت من هذا المصدر. لا يُسمح بالتثبيت الصامت خارج Google Play.
- لإصدارات tags، يحتاج GitHub Actions إلى secret باسم `ANDROID_DEBUG_KEYSTORE_BASE64` في **Settings → Secrets and variables → Actions**. لا تضع keystore أو قيمته في المستودع العام.
- يجب أن يطابق مفتاح التوقيع شهادة النسخة الحالية كي تُثبّت النسخة كتحديث وتحافظ على بياناتها. لا تغيّر المفتاح ما لم تختر الانتقال المتعمد إلى مفتاح توقيع جديد.

## البناء المحلي

المتطلبات: Node.js وJDK 17+ وAndroid SDK API 35.

```bash
npm ci
npm run build
cd android
./gradlew assembleDebug
```

الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk` (نسخة debug قابلة للتثبيت للتجربة). إعداد التوقيع والإصدارات الأصلية موضّح في [android/README.md](android/README.md).
