# توتي — خطتك الصحية

تطبيق خطة تغذية عربي لسندس، بواجهة React الحالية ضمن تطبيق Android أصلي مكتوب بـ Kotlin. يحافظ الغلاف على واجهة React ويعرضها محليًا داخل WebView، بينما يدير Android التخزين وجدولة التذكيرات.

## المزايا

- أوقات الوجبات قابلة للتعديل وتبقى محفوظة بين مرات التشغيل.
- ساعة تناظرية ورقمية حيّة، تتحرك عقاربها مع الوقت وتعرض الوجبة القادمة.
- تخزين الحالة والجدول محليًا في SQLite داخل مساحة التطبيق الخاصة؛ لا يتطلب حسابًا أو خادمًا.
- إشعارات مواعيد الوجبات المحلية، مع إعادة الجدولة بعد إعادة تشغيل الهاتف أو تغيير الساعة.
- تشغيل ملف «سندس يا عنوان المجد» المرفق مع كل تنبيه وجبة عبر قناة إشعارات Android.
- أذونات الإشعارات والكاميرا والميكروفون مع طلبها من المستخدم عند اختياره. لا تستخدم الواجهة الحالية الكاميرا أو الميكروفون.

## بناء APK

المتطلبات: Node.js وJDK 17+ وAndroid SDK API 35.

```bash
npm ci
npm run build
cd android
./gradlew assembleDebug
```

الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk` (نسخة debug قابلة للتثبيت للتجربة).
تفاصيل إعداد Android والتنبيهات في [android/README.md](android/README.md).
