# سندس دي أنا لنظام Android

تعمل واجهة React بطريقتين: يحاول التطبيق تحميل آخر نسخة من GitHub Pages عبر HTTPS، ويحتفظ APK بواجهة محلية احتياطية إذا لم يتوفر الإنترنت. تُحفظ الخطة اليومية ومواعيد الوجبات في قاعدة SQLite خاصة بالتطبيق (`sonds_private.db`).

## البناء المحلي

من جذر المستودع:

```bash
npm ci
npm run build
cd android
./gradlew assembleDebug
```

ينتج APK التجربة في `android/app/build/outputs/apk/debug/app-debug.apk`. يبني هذا الأمر الواجهة المحلية بمسارات نسبية كي تعمل كنسخة احتياطية داخل WebView.

## التحديث الهوائي لواجهة React

- صفحة الواجهة: <https://fszazo5-design.github.io/Sonds/>.
- ينشر `.github/workflows/pages.yml` الواجهة تلقائيًا عند كل دفع إلى فرع `main`؛ لا ينشئ Release ولا يحتاج APK جديدًا.
- عند تشغيل التطبيق يُحمّل WebView الصفحة المنشورة الأحدث. زر التحديث أعلى الشاشة يمسح cache الويب ويجلب الصفحة مجددًا، مع الحفاظ على بيانات SQLite المحلية.
- إذا تعذر الاتصال أو لم تعمل Pages، يعود WebView إلى واجهة React المضمّنة في APK. لا تُحذف بيانات الخطط عند هذا الانتقال.
- بعد تثبيت APK التمهيدي الداعم لـPages، تعديلات React وCSS وواجهة المستخدم تُنشر على الهواء عبر `main`. أما Kotlin أو AndroidManifest أو الأذونات أو سلوك المنبهات فيتطلب APK Android جديدًا.

## تحديث APK الأصلي (للتغييرات في Android فقط)

- من «إعدادات الأذونات» اختر «تحديث نظام Android (APK)» عند نشر إصدار Android جديد؛ ينزّل التطبيق `Sonds.apk` من أحدث GitHub Release ويطلب Android تأكيد التثبيت.
- يبني `.github/workflows/android-apk.yml` APK عند دفع tag يبدأ بـ `v`، أو عند تشغيل workflow يدويًا. لم يعد يبني APK تلقائيًا مع كل دفع إلى `main`.
- يلزم السماح مرة واحدة لتطبيق سندس دي أنا بالتثبيت من هذا المصدر. لا يُسمح بالتثبيت الصامت خارج Google Play.
- لإصدارات tags، يحتاج GitHub Actions إلى secret باسم `ANDROID_DEBUG_KEYSTORE_BASE64` في **Settings → Secrets and variables → Actions**. لا تضع keystore أو قيمته في المستودع العام.
- يجب أن يطابق مفتاح التوقيع شهادة النسخة الحالية كي تُثبّت النسخة كتحديث وتحافظ على بياناتها. استخدم السر الذي سبق إعداده للمستودع؛ لا تغيّره ما لم تختر الانتقال المتعمد إلى مفتاح توقيع جديد.

لإطلاق تحديث Android أصلي فقط:

```bash
git tag v1.0.6
git push origin v1.0.6
```

## الأذونات والتنبيهات

- يطلب التطبيق إذن الإشعارات من الزر المخصص في الواجهة، ويطلب الكاميرا/الميكروفون فقط عند ضغط أزرارهما؛ لا تُفتح الكاميرا أو تُسجّل الأصوات حاليًا.
- على Android 12 وما بعده يمكن تفعيل «التنبيهات الدقيقة» من إعدادات المنبهات الخاصة بالتطبيق؛ إن لم يُمنح الإذن تعمل الجدولة بوضع غير دقيق وفق قيود النظام.
- تستخدم جميع مواعيد الوجبات ملف `meal_reminder_laufey.mp3` المرفق كصوت قناة الإشعارات الجديدة. أنشأ التطبيق معرّف قناة جديدًا كي لا يستمر Android في استخدام الصوت المحفوظ للقناة القديمة. يتحكم Android بمستوى الصوت و«عدم الإزعاج» وإعدادات القناة، ويمكن للمستخدم تغييرها من إعدادات التطبيق.
- تحفظ أوقات الوجبات في SQLite وتُعاد جدولة المنبهات بعد إعادة تشغيل الجهاز أو تغيير الساعة/المنطقة الزمنية.
- قد تتطلب بعض الهواتف تعطيل تقييد البطارية للتطبيق كي لا تؤخر الشركة المصنّعة التنبيهات.
