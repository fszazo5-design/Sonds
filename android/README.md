# تطبيق توتي الصحي لنظام Android

واجهة React الحالية تُضمّن محليًا داخل تطبيق Android أصلي بغلاف Kotlin/WebView. تُحفظ الخطة اليومية وأوقات الوجبات في قاعدة SQLite خاصة بالتطبيق (`sonds_private.db`) مع نسخة مزامنة من حالة الواجهة. لا يحتاج تشغيل الواجهة إلى خادم ويب.

## البناء المحلي

من جذر المستودع:

```bash
npm ci
npm run build
cd android
./gradlew assembleDebug
```

ينتج APK التجربة في `android/app/build/outputs/apk/debug/app-debug.apk`.

## التحديث الهوائي عبر GitHub

- من «إعدادات الأذونات» في التطبيق اضغط «فحص تحديث التطبيق من GitHub». يقرأ التطبيق أحدث GitHub Release للمستودع العام، وينزّل `Sonds.apk` إذا كان إصدارًا أحدث.
- يتطلب تثبيت APK السماح مرة واحدة لتطبيق توتي بالتثبيت من هذا المصدر. بعد التنزيل يعرض Android شاشة التأكيد؛ لا يُسمح بالتثبيت الصامت خارج Google Play.
- يبني `.github/workflows/android-apk.yml` ملف APK على كل دفع إلى `main` ويحفظه كـ workflow artifact. دفع tag يبدأ بـ `v` (مثل `v1.0.1`) يبني APK وينشره في GitHub Releases ليكتشفه التطبيق.
- لإصدارات tags، أضف في GitHub: **Settings → Secrets and variables → Actions → New repository secret** باسم `ANDROID_DEBUG_KEYSTORE_BASE64`، وضع فيه النص من ملف Base64 لمفتاح التوقيع. لا تضع المفتاح أو ملف keystore في المستودع العام.
- هذا هو مفتاح debug الذي وقّع النسخة الحالية؛ استخدامه يسمح بتحديث النسخة المثبتة مع الحفاظ على بياناتها. توقيع debug مناسب للتوزيع المباشر عبر GitHub، لكنه ليس مفتاح نشر Google Play. احتفظ بنسخة آمنة منه.

بعد إضافة السر، انشر إصدارًا جديدًا مثلًا بالأوامر التالية:

```bash
git tag v1.0.1
git push origin v1.0.1
```

## الأذونات والتنبيهات

- يطلب التطبيق إذن الإشعارات من الزر المخصص في الواجهة، ويطلب الكاميرا/الميكروفون فقط عند ضغط أزرارهما؛ لا تُفتح الكاميرا أو تُسجّل الأصوات حاليًا.
- على Android 12 وما بعده يمكن تفعيل «التنبيهات الدقيقة» من إعدادات المنبهات الخاصة بالتطبيق؛ إن لم يُمنح الإذن تعمل الجدولة بوضع غير دقيق وفق قيود النظام.
- تستخدم جميع مواعيد الوجبات ملف `sondos_meal_reminder.mp3` المرفق كصوت قناة الإشعارات. يتحكم Android بمستوى الصوت و«عدم الإزعاج» وإعدادات القناة، ويمكن للمستخدم تغييرها من إعدادات التطبيق.
- تحفظ أوقات الوجبات في SQLite وتُعاد جدولة المنبهات بعد إعادة تشغيل الجهاز أو تغيير الساعة/المنطقة الزمنية.
- قد تتطلب بعض الهواتف تعطيل تقييد البطارية للتطبيق كي لا تؤخر الشركة المصنّعة التنبيهات.
